# 临床见习患者回述观察的证据范围与课程调整

这是医学人文教学资料的本地分析工作区。临床解释教学观察和患者回述记录，均为虚构演练资料，不含健康档案。

## 资料

`data/explanation-observations.csv` 是 UTF-8 编码的合成演练表。记录只描述教学观察和回述范围，不记录诊断、病历或患者身份。
`data/observation-forms.csv` 提供与其关联的方案、情境或组织资料，用于理解主表事实的适用范围。

字段含义：学生代号、情境代号、专科、复杂度、语言、回述状态、带教介入、观察表版本、日期。

表中代号只用于连接同一份演练资料，不对应真实人员、院校或患者。数据没有预先计算的统计结论。

## 运行

需要 Python 3.11 或更高版本，无第三方依赖。运行基线检查：

```sh
python3 -m unittest discover -s tests -v
```

`src/humanities_analytics/inputs.py` 提供通用 CSV 读取入口，将每行作为字符串字段返回。
